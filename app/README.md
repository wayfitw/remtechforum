# «Ремтехника» — AI-фотоинсталляция

Киоск: фото гостя → генерация 2–3 фотореалистичных кадров на площадке «Ремтехники» →
выбор → карточка с логотипом и подписью → печать + QR на цифровую версию.

Форк проекта «Машина времени: Сахалин»: движок (гейт качества фото, ArcFace,
composite-генерация, карточка, печать, деплой) взят без изменений, заменены
только бренд, локации и промпты.

Название бренда в текстах — **«Ремтехника»** (не RemTech), упоминаний XCMG нет:
правка от 01.09.2026. Латинское `remtech-photo` осталось только во внутренних
именах — папка проекта, systemd-сервис, конфиг nginx; гость их не видит.

## Быстрый запуск

**Windows:** `app\run.bat`  **macOS/Linux:** `app/run.sh` → http://localhost:8000

Без ключей в `backend/.env` работает демо-режим: флоу проходится целиком на
заглушках, генерации нет. Ключи и все параметры — в `backend/.env.example`.

## Что ещё нужно подставить

Сейчас в проекте стоят **заглушки** — с ними всё работает, но на экране видно, что это черновик:

1. **Знак «rt»** — нарисован по растровому макету (`tools/gen_brand_assets.py`).
   Придёт оригинал (SVG/AI) — положить вместо файлов выше, скрипт больше не нужен.
2. **Эталонные кадры площадок** — `backend/assets/references/cabin.jpg`, `site.jpg`,
   `service.jpg` сейчас плашки «заменить на фото площадки». Нужны реальные снимки:
   кадр без гостя, в нужном ракурсе, со свободным местом там, где встанет человек.
   Техника должна быть **на самом кадре** — по описанию модель рисует
   «похожий жёлтый экскаватор», а не конкретную машину с ливреей.
3. ~~Логотипы партнёров~~ — готовы: ExpoDrev Russia ’26, Segezha Group, Ратибор,
   «Интеллектуальные терминалы». Белые версии для интерфейса и цветные для карточки
   собирает `tools/import_partner_logos.py` из исходников в `Desktop/RemTech Форум`
   (у «Интеллектуальных терминалов» исходник взят из проекта «Сахалин»). Новый
   партнёр — добавить файл в `SOURCES` и прогнать скрипт.
4. **Фоновое видео** — `frontend/media/intro.mp4` + постер. Без него фон — чёрный
   градиент с фирменной диагональю, сайт работает.
5. **Шрифт подписи на карточке** — сейчас рукописный Caveat, наследство Сахалина.
   Под индустриальный стиль нужен брендовый или свободный гротеск:
   положить в `backend/assets/fonts` и поправить `_font("script")` в `compositor.py`.

## Структура

```
backend/
  main.py            FastAPI: /api/generate, /api/card, /api/print, /d/{id}
  gemini_client.py   шлюз генерации (цепочка провайдеров + stub)
  replicate_client.py Replicate: Seedream/nano-banana, face-swap
  facecrop.py        кропы лица/корпуса
  face_metric.py     ArcFace: гейт входа + ранжирование по сходству
  compositor.py      сборка карточки (фото + логотипы + подпись)
  config.py          конфигурация из .env, образ гостя
  locations.json     площадки и промпты
  assets/            references / logos / logos_card / fonts / output
frontend/
  index.html app.js styles.css   киоск-флоу
tools/
  gen_brand_assets.py  генерация знака и плашек-заглушек
  print_agent.py       агент печати на машине у принтера
```
